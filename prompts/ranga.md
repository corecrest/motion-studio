# Creative brief: Ranga motion

Create a restrained, premium, flat finance-app promotional video in a NEW folder under `videos/`.
Use the **actual supplied** Ranga logo, icon and brand specification. Do not reconstruct or invent these assets.
Use solid colors, a green-first visual identity, no purple, no glossy glassmorphism and no gratuitous glow.
Suggested scenes: identity reveal → payment setup → transfer movement → confirmation → minimal wordmark close.
Default deliverable: 8–12 seconds, 1080p, 30fps, silent MP4 (audio only when supplied and licensed).
Storyboard before coding; use deterministic GSAP motion. Provide representative frame snapshots and exported MP4.
